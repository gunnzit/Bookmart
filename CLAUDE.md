# Business requests go to the manager
For any request about running wrap&read (marketing, money, customers, stock, orders, the website, or "what needs my attention"), use the `manager` skill. It splits the work across the agents in `.claude/agents/` and reports back once. The owner gives one instruction and never briefs agents individually. Orders also arrive on the wrap&read HQ dashboard: "check my dashboard" means run the manager skill's dashboard section.
